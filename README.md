# 🔌 Floor Plan Cable Routing Studio

A Streamlit web app for annotating floor plans with cable routes, equipment, and labels.

## Features
- 📤 Upload PNG / JPG / BMP / WEBP floor plans
- 🖊️ Freehand pen for cable routes
- 📏 Lines, rectangles, circles, polygons
- 🔤 Text labels with adjustable font size
- 🧹 Eraser + transform (move/resize)
- 🎨 Full color customization (stroke + fill)
- ↩️ Undo / redo history
- 💾 Export annotated PNG
- 📄 Export annotation JSON (for re-import or processing)

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
